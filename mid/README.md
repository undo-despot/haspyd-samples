# mid ◆ акценти

Замість snare / clap / rim. Різкі удари, які відповідають на `low`.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| латунь на дерево | різкий удар із брязкотом | кинути латунну пластину на дерев'яний стіл з висоти 5–10 см |
| молоток по латуні | метал із довгим «хвостом» | удар молотком по латунній пластині, дати дозвучати |
| кусачки | сухий клік, як rimshot | клацнути кусачками чи плоскогубцями біля мікрофона |
