# tone ◆ тональні звуки

Звуки з чіткою висотою, з яких можна грати мелодії.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| латунна трубка / пластина | дзвін на одній ноті | вдарити й дати дозвучати; **визнач ноту тюнером і запиши її в назву варіації**, напр. `0_c4.wav` |
| склянка | чистий синусоподібний тон | мокрим пальцем по краю склянки, 2–3 с |

## У Strudel

```js
s("name").speed("<1 1.5 2 .75>")      // висота через швидкість
s("name*4").speed("1 1.25 1.5 2")     // міні-мелодія
s("name").slow(2).room(.9)            // довгий дзвін
```
