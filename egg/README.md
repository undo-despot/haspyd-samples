# egg ◆ easter eggs (｡•̀ᴗ-)✧

Фірмові звуки курсу. Для настрою, мемів і рубрики «баг дня».

## Що записати

| ідея | опис |
|---|---|
| «ой» | твоя реакція на помилку |
| сміх | короткий, живий |
| «ура» / «є!» | коли нарешті запрацювало |

## У Strudel

```js
s("~ ~ ~ name")          // «ой» в кінці кожного такту
s("name").degradeBy(.8)  // іноді, несподівано
```
