# texture ◆ простір і атмосфера

Довгі звуки під патерном: фон, середовище, напруга.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| вода | крапля, плюскіт, потік | окремими файлами; крапля коротка, потік 5–10 с |
| скрип металу / дроту | напружений звук | повільно гнути або терти дріт |
| кімната / вітер | фоновий шум | 10–20 с тиші місця, де ти працюєш |

## У Strudel

```js
s("name").slow(8).gain(.4)              // фон на 8 циклів
s("name:0*4").speed(perlin.range(.5,2)) // крапля, що «плаває»
s("name").lpf(800).room(1)              // далеко-далеко
```
