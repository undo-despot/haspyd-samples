# high ◆ дрібний пульс

Замість хетів і шейкерів. Тихі, швидкі, повторювані звуки.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| згарда коротко | закритий хет | один короткий різкий струс, глушити рукою одразу |
| згарда довго | відкритий хет, «вдих» фрази | довше брязкання, дати дозвучати |
| наждачка / напилок | шумовий шейкер | короткий рух наждачкою або напилком по металу |

## У Strudel

```js
s("name*8").gain(.5)               // рівний пульс
s("name*16").gain("<.3 .6>")       // дихання гучністю
s("name*8?").speed("<1 1.5>")      // ? = випадкові пропуски
```
