# low ◆ основа ритму

Замість kick. Низькі, тілесні удари, на яких тримається патерн.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| кулак по металу | глухий тілесний удар з легким металевим відгуком | кулак або долоня по металевому листу, мікрофон дуже близько |
| дно каструлі | низ із дзвоном | удар по дну великої каструлі чи миски, можна долонею або м'яким молотком |
