# voice ◆ голос ♪

Головна фішка бібліотеки. Голос як інструмент, ритм і текстура.

## Що записати

| ідея | опис | як записати |
|---|---|---|
| протяжне «а» | вокальний пед | одна нота, 2–3 с, рівно, без вібрато |
| гудіння «м» | тепла низька підкладка | закритим ротом, 2–3 с |
| склади | ритмічний вокал | «да», «на», «ла», «ко» — кожен окремим файлом, коротко |
| бітбокс | перкусія ротом | «к», «т», «ш», різкий вдих |
| слова | мова як ритм | одне-два слова українською, кожне окремо |

## У Strudel

```js
s("name:<0 1 2 3>*4")              // нарізка складів
s("name").slow(4).room(.9).lpf(2000)   // пед
s("name*8").speed("<1 -1>")        // назад кожен другий цикл
```
